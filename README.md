# Gdzie woda

Wyszukiwarka udokumentowanych odwiertow wiertniczych przy wskazanym adresie w Polsce.

Wpisujesz adres, dostajesz mape i tabele odwiertow z okolicy: na ilu metrach sie skonczyly i na jaka warstwe trafily.

Dane: Centralny Bank Danych Hydrogeologicznych (Bank HYDRO), Panstwowy Instytut Geologiczny - Panstwowy Instytut Badawczy.
Adresy: OpenStreetMap. Mapy: Esri.

Narzedzie pomocnicze - nie zastepuje odwiertu probnego.
